## Engine contract

`computeRead(rawInputs) → Read`

```js
Read = {
  inputs,                          // normalized copy actually used
  classification: { class: 'founder'|'founding_executive'|'hired_executive'|'hire',
                    score, total, selected, gloss, gates: { fullTime, finalSay } },
  band:           { lo, hi, pool, source, asOf, confidence, label },
  adjustments:    { banked: { dollars, pts, applied }, salary: { gap, pts, applied }, total },
  offer:          { pct|null, mode: 'percent'|'shares', position: 'below'|'within'|'above'|'unknown',
                    range: { lo, hi, grain }, gapPts: [lo, hi]|null, numberToSay: { value, sentence } },
  rounds:         { bootstrap: [], acquisition: [...], ipo: [...] },   // each: { round, d, stakeOffer|null, stakeMid }
  scenarios:      { bootstrap: cards[4], acquisition: cards[4], ipo: cards[4] },  // cards: zero, conservative, base, upside
  brief:          { headline, flags: [], questionsToAsk: [], text }, // text = plain-text brief for copy/paste
  sources:        [{ name, asOf }],
}
```

## Engine rules (final)

**Normalization** (`bounds.js`): every numeric field has `{ min, max, default, optional }`. Required fields: blank/NaN → default. Optional fields (`offeredSalary`, `offeredEquityPct`, `optionCount`, `fullyDilutedShares`, `strikePrice`): blank → `null`; `0` is a value. `idea` maps to `preseed` in every table.

| field                            | min | max       | default            |
| -------------------------------- | --- | --------- | ------------------ |
| months                           | 0   | 120       | 6                  |
| hoursPerWeek                     | 0   | 80        | 10                 |
| ratePerHour                      | 0   | 1000      | 150                |
| feesBilled                       | 0   | 5,000,000 | 0                  |
| marketSalary                     | 0   | 2,000,000 | role × stage table |
| offeredSalary                    | 0   | 2,000,000 | null               |
| offeredEquityPct                 | 0   | 100       | null               |
| optionCount / fullyDilutedShares | 0   | 1e12      | null               |
| strikePrice                      | 0   | 10,000    | null               |
| founders                         | 1   | 6         | 2                  |
| vestingYears                     | 1   | 10        | 4                  |
| cliffMonths                      | 0   | 24        | 12                 |
| roundsBeforeExit                 | 0   | 6         | per path           |

**Stage** = the last _closed_ priced round. Copy under the chips: "Currently raising your seed? Pick 'Pre-seed'."

**Offer input**: mode `percent` (default) or `shares` (`optionCount` / `fullyDilutedShares` → `pct = 100 × count / fd`). Copy: "Ask for the fully diluted share count; option counts alone mean nothing."

**Classification** (`classify.js`): chip weights per role sum to 8.5 (sets in the design doc). Gates: `fullTimeOnSigning` and `finalTechnicalSay` (yes/no, step 2).

- `joining = formation` → `founder` always (they hold founder shares); score < 3 → bottom third of the band with the light-load gloss.
- `joining = fractional_conversion` and `score ≥ 6` and `months ≥ 6` and `stage ≤ preseed` → `founder` ("de facto co-founder") with the founders stepper shown on step 1 when this becomes reachable.
- otherwise `score ≥ 3.5` → `founding_executive`; `2 ≤ score < 3.5` → `hired_executive`; `< 2` → `hire`.
- Either gate = no (non-formation only) → class capped at `hired_executive`, gloss names the gate.

**Team pool by stage** (`benchmarks.js`, founding-team fully diluted %): pre-seed/idea 90 (after a ~10% pool; inferred, EquityList/Index), seed 56 (Carta 2026), Series A 36 (Carta 2026), Series B+ 27 (Carta 2026, AI-team median; inferred for general).

**Founder band**: `base = pool / founders`; `lo = 0.75 × base`; `hi = min(1.25 × base, pool − (founders − 1) × 0.5 × base)`; ceo_builder `lo = base`. Solo founder: `lo = 0.75 × pool`, `hi = pool`. No further dilution multiplication (the pool already reflects the stage).

**Non-founder bands**: table in the design doc, each row `{ lo, hi, source, asOf, confidence }`. Engineer and ceo_builder rows are `confidence: 'inferred'` until TODO 2 lands and print "inferred" inline.

**Adjustments** (`adjustments.js`): exchange rate by stage as designed; `banked` only for `fractional_conversion`; caps +5 / +4, combined +7, floor −2; apply to every class.

**Range and rounding**: `raw = [lo + adj, hi + adj]`; `grain = raw.lo < 2 ? 0.05 : 0.5`; round both ends to `grain`; if `hi − lo < grain` then `hi = lo + grain`; floor `lo ≥ 0.05`. Test: for every cell × every adjustment in {−2, 0, +1.8, +7}: `0 < lo < hi`.

**Number to say**: below → midpoint (rounded at `grain`) with the range in the sentence; within → the offer ("Your offer sits inside the band. Hold the percent; negotiate salary, vesting, or acceleration."); above → the offer ("Above the band for this work. Hold."). No offer → sentence without the "I'm at" clause; timeline and scenarios use the midpoint series; Ask sanity hidden.

**Dilution** (`dilution.js`): per-round medians as designed; remaining rounds by stage as designed; `roundsBeforeExit` default: bootstrap 0, acquisition 2, ipo all remaining; editable in Show the math (clamped to remaining). All three paths always computed; toggle preselects the declared path (acquisition when unknown).

**Scenarios** (`scenarios.js`): four cards per path, `zero` first: "$0 — most startup equity ends here" with base-rate copy; then conservative / base / upside at the designed valuations (editable). Options with `mode = shares` and `strikePrice`: `value = max(0, stake × exitValuation − optionCount × strikePrice)`; otherwise the exercise cost line reads "not subtracted (enter your option count and strike to include it)". Every card footer: "Assumes fully vested, no liquidation preferences, no tax."

**Brief** (`brief.js`): headline sentence; flags: cliff > 12 months, vesting > 4 years, instrument unsure, gate = no, inferred band; questions to ask: fully diluted share count, option pool size and refresh, preference stack, acceleration on change of control; `text` is the plain-text brief for the copy button (same content as print).
